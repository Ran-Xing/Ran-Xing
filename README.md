Hi, I'm Ran-Xing.

I started out tinkering with security tooling, Android ADB, and macOS system utilities. Most of my public repos live under [XRSec](https://github.com/XRSec).

Lately, most of my time goes into local-first desktop tools and the plumbing around coding agents: keeping prompt caches from breaking mid-session, wrangling orphaned agent processes, or putting a small MCP bridge in front of local files so I don't have to glue five scripts together.

**Stack I reach for most:** Rust, Go, Swift (macOS), TypeScript, Kotlin, and Tauri v2 when a CLI needs a window.

**A few tools I actually keep on my own machine:**
- [Screen-Remote](https://github.com/XRSec/Screen-Remote) & [wifi-adb](https://github.com/XRSec/wifi-adb), for poking at an Android device without dragging a laptop out.
- [DFU-Tools](https://github.com/XRSec/DFU-Tools), so I don't have to look up Apple Silicon DFU steps for the hundredth time.
- [pi-prompt-diet](https://github.com/XRSec/pi-prompt-diet) & [antigravity-gemini-gateway](https://github.com/XRSec/antigravity-gemini-gateway), to cut token waste and rate-limit retries in my coding sessions.
- [SAFE_DELETE](https://github.com/XRSec/SAFE_DELETE) (`rmf`), because I don't trust myself (or an agent) with raw `rm -rf`.
